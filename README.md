# For Anziya — Happy Birthday 🎁

A private, cinematic birthday tribute website.

## Structure
- `index.html` — entry (loader → gift → story → finale)
- `css/` — `style.css` (theme) · `fonts.css` + `fonts/` (local woff2)
- `js/` — `config.js` (all copy) · `particles.js` · `script.js` · `vendor/` (gsap, ScrollTrigger, lenis)
- `assets/photos` · `assets/videos` — media
- `elton-gf/` — standalone copy of the site

Fully self-contained: no CDNs, no build step. Open `index.html` or deploy as static.
